# Unit of Work Dependency — Pandora

---

## 1. ユニット間依存マトリクス

| → 依存される / 依存する ↓ | U1 Web App | U2 AWS Infra |
|---------------------------|:----------:|:------------:|
| **U1 Web App** | self | ✓（ランタイム / 環境変数） |
| **U2 AWS Infra** | - | self |

- U1 → U2: ランタイムで AWS リソース（Cognito/DDB/S3/Bedrock）にアクセス。リソース ID は環境変数で受領
- U2 → U1: なし（Infra は Web App を参照しない）
- 開発時の構築順: **U2 先行 → U1**

---

## 3. ビルド/デプロイ依存

| 操作 | 依存 |
|------|------|
| U2 `cdk deploy` | なし（独立） |
| U2 `cdk deploy` 後 | Output 値を Vercel 環境変数へ反映（手動 or スクリプト） |
| U1 Vercel デプロイ | Vercel に環境変数が設定済みであること |

---

## 4. データ契約

データ自体は U2 がプロビジョンしたインフラ上に存在し、U1 がアクセス・変更する。**スキーマ管理責任は U1**（DynamoDB の論理モデルは Functional Design で確定）。

---

## 5. 同時開発の可否

- 初期ブートストラップ: **直列**（U2 → U1）
- 機能追加局面: **並列可**（U2 にインフラ追加が必要な場合のみ U1 が待つ）
