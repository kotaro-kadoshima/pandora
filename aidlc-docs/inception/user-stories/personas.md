# Personas — Pandora

**形式**: 軽量（役割と動機のみ）/ Q1=A, Q2=A 準拠
**作成日**: 2026-05-07

---

## P1. 探究者リコ — 実験者

- **役割**: 自分自身を実験台にして、日常の迷信や噂の効果を検証したい人
- **主な動機**: 「自分には効くのか？」を確かめたい、記録を残す行為そのものに楽しさを感じる
- **典型的な行動**: 題材を思いついたら投稿し、AI 生成の実験設計を採用、日次でコツコツ記録
- **痛点**: 一人で実験設計を組み立てられない / 続けるモチベーションが切れる

## P2. 眺める人ハル — 閲覧者 / 新規ユーザー候補

- **役割**: 他人の研究結果を眺めるのが好き。自分でも始めるきっかけを探している
- **主な動機**: 「気になる、やってみたい」が止まらない知的好奇心
- **典型的な行動**: タイムラインを延々スクロール、興味のある題材で詳細を開き沼る、最終的にサインアップして自分も実験開始
- **痛点**: 何から試せばいいか分からない / どの題材が「自分にも刺さるか」が不明

## P3. 並走者ナナ — グループ参加者

- **役割**: 同じ題材で他者と並走し、結果を比較・対話したい人
- **主な動機**: 自分の n=1 を他者の n=1 と並べて意味を見出したい、コミュニティで盛り上がりたい
- **典型的な行動**: 題材グループの一覧で他者と自分の進捗を比較、コメントやリアクションで反応する
- **痛点**: 他者の進捗が見えないと比較できない / 一人だと続かない

## P4. 疑い深いケン — 懐疑的レビュワー

- **役割**: AI 提案や題材の「確からしさ」を精査するタイプ
- **主な動機**: 雑な提案や根拠の薄い実験は受け入れられない、エビデンスを確認したい
- **典型的な行動**: AI が提示する確からしさ・根拠リンクを必ず確認、他者の記録のサンプルや手順遵守も観察
- **痛点**: 根拠が示されないと信頼できない / 個人差を一般化されたくない
