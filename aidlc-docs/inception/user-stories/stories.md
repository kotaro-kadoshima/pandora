# Epic E1: 認証・オンボーディング

## US-01 新規登録 ｜ Must

- **As a** ユーザー
- **I want** メールアドレスとパスワードでアカウントを作成したい
- **So that** 自分の研究を投稿・記録できる状態になる

**受け入れ基準**

- Given 未登録のメールアドレスを入力した状態で
- When サインアップを実行する
- Then アカウントが作成され、確認手段が完了したのちログイン状態になる

- Given 既に登録済みのメールアドレスで
- When サインアップを実行する
- Then 登録済みである旨のエラーが表示される

**ペルソナ**: リコ, ナナ, （ハルがサインアップする時にも）

---

## US-02 ログイン / ログアウト ｜ Must

- **As a** ユーザー
- **I want** 既存アカウントでログイン・ログアウトしたい
- **So that** 自分の記録を続けて見られる/離席時に守れる

**受け入れ基準**

- Given 登録済みのメールアドレスとパスワードを入力した状態で
- When ログインを実行する
- Then 自分のホーム画面が表示される

- Given ログイン済みの状態で
- When ログアウトを実行する
- Then 認証必須ページへのアクセスが拒否される（ログイン画面へ戻る）

**ペルソナ**: 全員

# Epic E2: マイ研究所（題材→AI設計→開始）

## US-03 題材投稿と AI 実験設計の生成 ｜ Must

- **As a** ユーザー
- **I want** 興味のある題材（例「目の体操で視力が回復するか」）を投稿し、AI に実験設計を組んでほしい
- **So that** 素人でも"ちゃんとした"実験を始められる

**受け入れ基準**

- Given ログイン済みのユーザーが題材テキストを入力した状態で
- When 「実験設計を生成」を実行する
- Then 30 秒以内に以下が画面に提示される:
  - 題材の確からしさ要約
  - 実施方法の候補（複数）
  - 推奨スケジュール（頻度・時間）
  - 効果測定の方法
  - 日次チェック項目セット（数値/セレクト/チェックボックス/スライダー/画像/テキスト の組み合わせ）

- Given AI 生成中に通信エラーが発生した状態で
- When 結果待ちが失敗した
- Then 失敗メッセージとリトライ動線が表示される

**ペルソナ**: リコ

---

## US-04 AI 提案を確認して研究を開始 ｜ Must

- **As a** ユーザー
- **I want** AI 提案の実験設計を確認・採用して、自分の研究として開始したい
- **So that** 計画通りに記録を始められる

**受け入れ基準**

- Given AI 生成された実験設計が提示されている状態で
- When 「この設計で開始」を実行する
- Then 自分の研究として保存され、本日からの日次記録対象になる

- Given AI 生成された実験設計が提示されている状態で
- When 一部の方法/チェック項目を選択解除する
- Then 採用範囲のみが研究設定として保存される

**ペルソナ**: リコ, ケン（精査して採用判断する）

# Epic E3: 日次記録

## US-05 日次でチェック項目を記録 ｜ Must

- **As a** ユーザー
- **I want** 自分の研究のチェック項目を毎日記録したい
- **So that** 経過を追跡し効果を判断できる

**受け入れ基準**

- Given 自分の進行中の研究があり、本日の記録が未入力の状態で
- When チェック項目を入力して保存する
- Then その日の記録が保存され「記録済み」として表示される

- Given 同じ日にすでに記録が存在する状態で
- When 同日の記録を保存する
- Then 既存記録が上書きされる（または編集確認が出る）

**ペルソナ**: リコ, ナナ

---

## US-06 自分の経過を時系列・グラフで閲覧 ｜ Must

- **As a** ユーザー
- **I want** 自分の研究の記録を時系列・グラフで眺めたい
- **So that** 効果の傾向を視覚的に判断できる

**受け入れ基準**

- Given 自分の研究に複数日の記録がある状態で
- When 「経過」画面を開く
- Then 数値項目はライングラフ、セレクト項目は分布、画像は時系列ギャラリーとして表示される

**ペルソナ**: リコ

---

## US-07 記録時の画像アップロード ｜ Must

- **As a** ユーザー
- **I want** チェック項目に画像を添付してアップロードしたい
- **So that** 肌・体型などの視覚的変化を記録できる

**受け入れ基準**

- Given 画像アップロード項目を含む研究で記録中の状態で
- When 画像を選択して保存する
- Then 画像が S3 に保存され、当日の記録に紐付けて表示される

- Given アップロード対象が許容サイズ（仮: 10MB）を超える状態で
- When 保存しようとする
- Then エラーが表示され、保存されない

**ペルソナ**: リコ

# Epic E4: 公開タイムライン

## US-08 ゲストでも公開タイムラインを閲覧 ｜ Must

- **As a** ユーザー（未ログイン含む）
- **I want** 公開された他者の研究一覧を眺めたい
- **So that** 興味を持って自分も始めるきっかけにできる

**受け入れ基準**

- Given 未ログイン状態で
- When トップページを開く
- Then 公開された研究の一覧（題材・実施者ハンドル・経過日数・結果サマリ）が表示される

- Given 一覧画面で
- When ある研究をクリックする
- Then 題材詳細ページに遷移する

**ペルソナ**: ハル

---

## US-09 題材詳細で日次記録を閲覧 ｜ Must

- **As a** ユーザー（未ログイン含む）
- **I want** 個別の研究詳細で日次記録（グラフ・画像含む）を見たい
- **So that** その研究の進捗・結論を確認できる

**受け入れ基準**

- Given 公開された研究の詳細ページを開いた状態で
- When ページを閲覧する
- Then 題材説明、実験設計、日次記録（グラフ/ギャラリー）が表示される

**ペルソナ**: ハル, ケン

# Epic E5: 題材グループ（比較・反応）

## US-10 同題材グループの記録を一覧比較 ｜ Must

- **As a** ユーザー
- **I want** 同じ題材に取り組む他者の記録を一覧で比較したい
- **So that** 個人差を可視化し、自分の経過と相対化できる

**受け入れ基準**

- Given 自分が進行中の研究と同題材で他者の研究が存在する状態で
- When 「題材グループ」を開く
- Then 全員の進捗・主要数値が並べて表示される

**ペルソナ**: ナナ

---

## US-11 他者の記録にコメントする ｜ Should

- **As a** ログイン済みユーザー
- **I want** 他者の日次記録や題材にコメントしたい
- **So that** 反応を伝え合うことで継続のモチベーションになる

**受け入れ基準**

- Given グループ内の他者の記録を開いた状態で
- When コメントを投稿する
- Then 直後に同記録のコメント欄に表示される

- Given 未ログイン状態で
- When コメント欄を操作する
- Then ログインを促される

**ペルソナ**: ナナ

---

## US-12 他者の記録にリアクションする ｜ Should

- **As a** ログイン済みユーザー
- **I want** 他者の記録に絵文字スタンプ等でリアクションしたい
- **So that** 軽い反応で交流が生まれる

**受け入れ基準**

- Given グループ内の他者の記録を開いた状態で
- When リアクションを選んで送る
- Then 集計が即時に反映される

- Given 同じ記録に同じリアクションを既に送っている状態で
- When 同じリアクションを再度送る
- Then 取り消し（トグル）として動作する

**ペルソナ**: ナナ

# Epic E6: AI 確からしさ提示

## US-13 AI が題材の確からしさを根拠付きで提示 ｜ Should

- **As a** ユーザー
- **I want** AI 生成された実験設計画面で「題材の確からしさ」とその根拠（参照リンクや要約）を見たい
- **So that** 採用するかどうかをエビデンスベースで判断できる

**受け入れ基準**

- Given 題材を投稿し AI 生成が完了した状態で
- When 設計画面を開く
- Then 「確からしさ」セクションに概略評価（例: 強い/中程度/弱い/不明）と根拠（参照URL or サマリ）が表示される

- Given 根拠の取得に失敗した状態で
- When 設計画面を開く
- Then 「根拠取得不可」のラベルが付き、ユーザーが採用判断できる注釈が出る

**ペルソナ**: ケン, リコ

## INVEST 準拠チェック（自己点検）

|------|------|
| Independent | エピック内では一部依存（US-04 は US-03 後）。エピック間は概ね独立 |

| Testable | Given-When-Then で記述、AC は確認可能 |
